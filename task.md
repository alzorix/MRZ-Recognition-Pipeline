# Задача

Необходимо по фотографии документа распознать данные машиночитаемой зоны

Датасет для тестов:
data.json

Имеется модель для выделения машиночитаемой зоны на документе
mrz.pt для архитектуры YOLO 26
```python
model = YOLO("mrz.pt") 
```
которая находит в файле изображении документа машиночитаемую зону, и выделяет ее.

Для распознавания текста необходимо использовать библиотеку PaddleOCR

```python
from paddleocr import PaddleOCR

ocr = PaddleOCR(
    use_doc_orientation_classify=False,  # Отключаем классификацию ориентации документа
    use_doc_unwarping=False,              # Отключаем выпрямление документа
    use_textline_orientation=False,       # Отключаем определение ориентации строк
    lang='en',                            # или 'ru', 'en' и т.д. [citation:7]
    ocr_version="PP-OCRv5",                 # Явно указываем версию (необязательно, но наглядно) [citation:1]
    enable_mkldnn=False
)
```

Полученные фрагменты текста необходимо разложить по полям стандарта MRZ
